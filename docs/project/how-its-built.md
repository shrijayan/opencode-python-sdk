# How it's built

Most of this package is generated by [Ferrule](https://github.com/shrijayan/ferrule) from OpenCode's own contract;
this SDK's own features are written by hand next to the generated code.

```text
@opencode/protocol (npm) ─bun codegen/extract─▶ spec/contract.json ─scripts/opencode─▶ openapi.json + stainless.yml ─ferrule─▶ src/opencode
```

## 1. Extract the contract

`codegen/extract/extract.ts` loads `ClientApi` from the published `@opencode/protocol` package, the same Effect
`HttpApi` definition the official TypeScript client is built from. It exports every endpoint with its inputs,
outputs and declared errors, and every schema as JSON Schema, into `spec/contract.json`.

## 2. Convert it to OpenAPI

`scripts/opencode/contract_to_openapi.py` turns the contract into `openapi.json`, and
`scripts/opencode/config_models.py` names every schema as a model in `stainless.yml`, so the types keep the names
this SDK has always exported (`SessionInfo`, `AgentInfo`). Both are plain Python with no dependencies, and give
byte-identical output for the same contract.

## 3. Generate with Ferrule

Ferrule reads `openapi.json` and `stainless.yml` and writes:

| Output | What it contains |
| --- | --- |
| `src/opencode/types/` | pydantic models for responses, `TypedDict` params for requests |
| `src/opencode/resources/` | A sync and an async class per API group, with typed arguments and docstrings |
| `src/opencode/_client.py` | `Opencode` and `AsyncOpencode` |
| `src/opencode/_base_client.py`, `_streaming.py`, `pagination.py`, ... | The runtime: requests, auth, retries, timeouts, server-sent events, cursor pages |
| `tests/`, `examples/agent/`, `api.md` | Tests against a mock server, runnable recipes, the method table |

`ferrule.lock` lists every generated file with its hash.

## 4. Hand-written features

| Module | Responsibility |
| --- | --- |
| `lib/_client.py` | The clients `opencode.Opencode` exports: `directory`, `transport`, `events`, `rpc`, `pty`, `session.run`, `from_service`, `wait_until_ready` |
| `_events.py` | The event hub behind `client.events` |
| `_rpc.py`, `_pty.py` | Typed plugin RPC and PTY connections |
| `_server.py`, `_service.py`, `service.py` | `OpencodeServer` and the background service |
| `_errors.py` | An exception class for every declared server error |
| `testing.py` | The fake server |

## Keeping it current

A nightly workflow checks for new `@opencode/protocol` releases and opens a pull request with the new contract,
`openapi.json` and `stainless.yml`. Merging it runs Ferrule, which commits the new generation on the `generated`
branch and opens a `ferrule/regenerate` pull request that merges it three ways, so hand-written code and edits to
generated files survive, labelled with the semver bump of the public API change. See
[Contributing](contributing.md) for running it locally.
